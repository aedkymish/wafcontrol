How to use an IP list

  1. Create a list and choose its type: Allow (only these IPs may access) or Deny (block these IPs).
  2. WafControl writes it as an include file for every installed web server and reloads it.
  3. Add the include line once to the site config where you want it applied (examples below). Later edits of the list apply automatically — no need to touch the site config again.
